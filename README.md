# Ascension — pre-alpha

Аскеншн (англ. "Ascension" ("Возвышение")) - это мессенджер-соцсеть, в которой может быть анархия лютейшая. Только аккаунт создайте, да канал наверно. Вам тоооооочно понравится этот мессенджер.

Простой десктопный мессенджер на Python (PyQt6 + WebSocket). Личные сообщения, друзья по нику, каналы (broadcast-чаты как в Telegram). Пока pre-alpha — многое ещё не реализовано (шифрование, история сообщений на сервере, статусы "печатает" и т.д.).

## Возможности

- Личные сообщения между пользователями в реальном времени
- Добавление друзей по нику
- Каналы: создание, вступление, широковещательные сообщения всем участникам
- Интерфейс на английском и русском (переключается на лету)
- Онлайн/офлайн статус друзей

## Установка

```bash
git clone https://github.com/tap0chk1n/ascension.git
cd ascension_prealphav001
pip install -r requirements.txt
```

## Запуск

Сначала сервер (можно на своей машине или на любом сервере в сети):

```bash
python server.py
```

Затем клиент (можно запускать сколько угодно раз с разными никами):

```bash
python client.py
```

По умолчанию клиент подключается к `ws://localhost:8765` — если сервер крутится на другой машине, поменяйте `SERVER_URL` в начале `client.py`.

## Структура проекта

```
ascension(alpha, beta, какая версия у вас)/
  client.py        — десктопное приложение (PyQt6)
  server.py        — сервер (asyncio + websockets)
  requirements.txt
  locales/          — переводы интерфейса (en.json, ru.json)
  assets/           — иконка и логотип
```

## Добавление перевода на новый язык

1. Скопируйте `locales/en.json` в `locales/<код_языка>.json` (например `locales/fr.json`)
2. Переведите значения (ключи не трогайте)
3. Добавьте строку в список `LANGUAGES` в `client.py`:
   ```python
   LANGUAGES = [
       ("en", "English"),
       ("ru", "Русский"),
       ("fr", "Français"),  # новая строка
   ]
   ```
4. Пришлите Pull Request
